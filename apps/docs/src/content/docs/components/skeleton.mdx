`Skeleton` giữ chỗ cho nội dung đang tải để layout không nhảy khi dữ liệu về. Mỗi instance là một hình dạng; phía gọi xếp nhiều skeleton để dựng bố cục.

## Cách dùng

```tsx
import { Skeleton } from '@enterprise-ui/components';

export function OrderCardSkeleton() {
  return (
    <div style={{ display: 'grid', gap: '0.75rem' }}>
      <Skeleton variant="rect" height={160} />
      <Skeleton width="70%" />
      <Skeleton width="40%" />
    </div>
  );
}
```

`text` cao `1em` và rộng 100%; `circle` mặc định 32×32; `rect` cao 80px. `width`/`height` nhận số (px) hoặc chuỗi CSS; `style` của phía gọi được merge sau cùng nên có thể ghi đè.

## Props

| Prop      | Kiểu                           | Mặc định     | Mô tả                    |
| --------- | ------------------------------ | ------------ | ------------------------ |
| `variant` | `'text' \| 'circle' \| 'rect'` | `'text'`     | Hình dạng.               |
| `width`   | `CSSProperties['width']`       | theo variant | Chiều rộng; số thành px. |
| `height`  | `CSSProperties['height']`      | theo variant | Chiều cao; số thành px.  |

Ngoài ra nhận thuộc tính của `<span>` trừ khi bị props trên ghi đè; `aria-hidden` luôn là `true`.

## Accessibility

- Mọi skeleton đều `aria-hidden="true"` — đây là placeholder thị giác, không phải nội dung.
- Hãy thông báo trạng thái tải bằng `Spin`, `role="status"` hoặc live region; đừng dựa vào skeleton để truyền đạt "đang tải".
- Shimmer tắt hoàn toàn khi `prefers-reduced-motion: reduce`; khối chuyển sang màu phẳng `--surface-muted`.
- Khi dữ liệu về, thay skeleton bằng nội dung thật; không giữ cả hai để tránh layout nhấp nháy.
