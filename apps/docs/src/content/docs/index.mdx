## Bắt đầu nhanh

Cài package, import stylesheet một lần và bọc ứng dụng bằng `ThemeProvider`.

```bash
npm install @enterprise-ui/components
```

```tsx
import { Button, ThemeProvider } from '@enterprise-ui/components';
import '@enterprise-ui/components/style.css';

export function App() {
  return (
    <ThemeProvider>
      <Button variant="primary">Tạo đơn hàng</Button>
    </ThemeProvider>
  );
}
```

## Nguyên tắc thiết kế

- **Màu thương hiệu tiết chế.** Xanh chủ đạo cho hành động chính, cam cho điểm nhấn — khoảng 10% diện tích.
- **Bàn làm việc sáng.** Nền trắng, sidebar trắng, viền mảnh; mật độ compact là mặc định.
- **Component thuần trình bày.** Dữ liệu vào qua props, sự kiện ra qua callback; không fetch bên trong.
- **Truy cập bàn phím trước.** Focus ring rõ, dialog trap focus, tab điều hướng bằng phím mũi tên.
