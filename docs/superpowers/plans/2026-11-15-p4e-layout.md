# P4e Layout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the P4e layout primitives — `Divider` and `Accordion` — with docs pages, closing the P4 roadmap.

**Architecture:** Two independent presentational components in their own folders under `packages/components/src/`. `Divider` renders a native `<hr>` for the unlabelled horizontal case and `role="separator"` divs for vertical/labelled cases. `Accordion` is a WAI-ARIA disclosure list (button inside a heading, persistent hidden panels) with single/multiple controlled or uncontrolled state. Both are exported from the package root with public types, documented by two Astro pages and demos, and use only existing tokens.

**Tech Stack:** React 18, TypeScript strict, CSS Modules with `var(--…)` tokens, Vitest + Testing Library (no user-event), Astro/Starlight docs, Vite.

**Spec:** `docs/superpowers/specs/2026-11-15-p4e-layout-design.md`

**Branch:** `feat/p4e-layout` from `main`.

## Global Constraints

- Zero runtime deps; TS strict, no `any`.
- CSS Modules + `var(--…)` tokens only — no hardcoded hex in components (repo-wide `css-conventions.test.ts`).
- Presentational only: data in via props, events out via callbacks; no fetching, no timers.
- Component folder layout: `X.tsx + X.module.css + types.ts + index.ts + X.test.tsx`, re-exported from `packages/components/src/index.ts` (component **and** public types).
- Vitest globals are on (`test`/`expect`/`vi` need no import); only `@testing-library/react` helpers are imported.
- `data-size={size}` in a component requires both `[data-size='sm']` and `[data-size='md']` blocks in its module CSS.
- `data-size` selectors are scoped to the component root so an ancestor's `data-size` cannot leak in.
- Docs are Astro MDX under `apps/docs/src/content/docs/`; every fenced `tsx` block is typechecked by `npm run docs:snippets` and must be self-contained.
- Full gate before push: `npm test` → `npm --workspaces run typecheck --if-present` → `npm run docs:snippets` → `npm run lint` → `npm run format:check` → components/showcase/docs builds.
- Mutants: back up with `cp <file> <file>.bak`, apply the mutant, run the named test, restore with `cp <file>.bak <file>` — never `git checkout <file>`.

## Review Focus

- The unlabelled horizontal divider is a native `<hr>`; vertical and labelled variants are `role="separator"` divs with the right `aria-orientation`.
- A labelled horizontal divider exposes its text as the accessible name and hides the visible copy from AT; label/align on a vertical divider is ignored.
- Accordion single vs multiple is type-safe: `values` only exists with `multiple`, `onChange` payload matches the mode.
- Panels stay mounted behind `[hidden]`, so form state survives collapse; every `aria-controls` points at a present node.
- Controlled values win even for disabled items; uncontrolled seeds skip disabled/unknown ids; a disabled trigger cannot toggle by click or keyboard.
- The root does not clip overflow, so popovers inside panels work; duplicate item ids warn in development.
- Up/Down/Home/End move focus only, skip disabled headers, wrap, and ignore IME keystrokes.

Each line gets a named test in the task that owns the code.

`types.ts` exactly as the Interface block. `Divider.tsx`:

```tsx
import type { ReactNode } from 'react';
import { cx } from '../internal/cx';
import styles from './Divider.module.css';
import type { DividerProps } from './types';

export function Divider({
  orientation = 'horizontal',
  label,
  spacing = 'md',
  align = 'center',
  className = '',
  ...rest
}: DividerProps) {
  // Drop children if a JS caller bypasses the type: <hr> is a void element and
  // would otherwise throw when the extra key reaches it.
  const { children: _children, ...rootProps } = rest as typeof rest & { children?: ReactNode };
  // A whitespace-only label has no accessible name after trimming, so it takes the
  // same path as `label=""` (plain `<hr>`) instead of a nameless separator.
  // The `typeof` guard keeps a JS caller that bypasses the type (null, number) from
  // crashing on `.trim()`.
  const labelled = orientation === 'horizontal' && typeof label === 'string' && label.trim() !== '';
  const shared = {
    ...rootProps,
    'data-orientation': orientation,
    'data-spacing': spacing,
    'data-align': labelled ? align : undefined,
    'data-labelled': labelled ? '' : undefined,
    className: cx(styles.root, className),
  };

  if (orientation === 'vertical') {
    return <div {...shared} role="separator" aria-orientation="vertical" />;
  }
  if (labelled) {
    return (
      <div {...shared} role="separator" aria-orientation="horizontal" aria-label={label}>
        <span className={styles.label} aria-hidden="true">
          {label}
        </span>
      </div>
    );
  }
  return <hr {...shared} />;
}
```
