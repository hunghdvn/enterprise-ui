# Release 0.1.0 + Changesets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `@enterprise-ui/tokens` and `@enterprise-ui/components` publishable to npm public at `0.1.0`, with changesets versioning and GitHub Actions OIDC trusted publishing.

**Architecture:** Add changesets at the root (fixed version group), publishable metadata to both packages, a release workflow that runs the full gate then opens a Version Packages PR or publishes, and README/LICENSE/docs for the npm pages. The first publish is a documented manual bootstrap because npm requires the package to exist before a trusted publisher can be attached.

**Tech Stack:** npm workspaces, `@changesets/cli` 2.31.1, `@changesets/changelog-git` 0.2.1, `changesets/action` v1.7.0, GitHub Actions OIDC, Node 24 in the release job.

**Spec:** `docs/superpowers/specs/2026-11-18-release-01-design.md`

**Branch:** `chore/release-01` from `main`.

## Global Constraints

- Root is private; `packages/tokens` and `packages/components` are publishable.
- Fixed version group: `tokens` and `components` always release together.
- Components depends on tokens as `^0.1.0`, not `*`.
- React peer stays `^18.3.0`.
- Local/CI Node 20 must keep working; only the release job uses Node 24.
- Release job uses npm ≥ 11.5.1 (Node 24 + `npm install -g npm@11`); `id-token: write`; no `NPM_TOKEN`.
- `dist/` is gitignored — build components before any pack/publish.
- `.superpowers/` is gitignored scratch; never commit it.
- Full gate before push: `npm test`, all-workspace typecheck, `docs:snippets`, lint, format check, components/showcase/docs builds.

## Review Focus

- `npm pack` must include `README.md`, `LICENSE`, `dist/` (components) and all `*.css` (tokens) — a missing file breaks the npm page or the import.
- `@enterprise-ui/tokens/all.css` must resolve through the new `exports` map — a wrong pattern breaks the components build and the emitted `dist/index.d.ts`.
- `fixed` (not `linked`) is required — components bundles token CSS, so versions must move together.
- The release workflow must have `id-token: write`, `registry-url`, Node 24 and npm ≥ 11.5.1 — a missing piece makes OIDC publish fail.
- The first publish is manual; the plan must not assume OIDC works on a package that does not exist yet.
- `changeset status` must resolve the fixed group — a typo leaves versions unbumped.
- `getting-started.mdx` must not tell consumers to use an internal registry after the package is public.

### Task 2: Release workflow (OIDC)

**Files:**

- Create: `.github/workflows/release.yml`

**Interfaces:**

- Consumes: root scripts `version:packages` and `release` from Task 1.
- Produces: a workflow that opens the Version Packages PR when changesets exist and publishes when the version PR is merged.

- [ ] **Step 1: Add the workflow**

```yaml
name: Release

on:
  push:
    branches: [main]
  workflow_dispatch:

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: false

permissions:
  contents: write
  pull-requests: write
  id-token: write

jobs:
  release:
    runs-on: ubuntu-latest
    timeout-minutes: 40
    steps:
      - name: Checkout
        uses: actions/checkout@11d5960a326750d5838078e36cf38b85af677262 # v4
        with:
          fetch-depth: 0
      - name: Set up Node
        uses: actions/setup-node@49933ea5288caeca8642d1e84afbd3f7d6820020 # v4
        with:
          node-version: 24
          registry-url: 'https://registry.npmjs.org'
      - name: Install npm
        run: npm install -g npm@11
      # Keep these gate steps in sync with .github/workflows/ci.yml (verify job).
      - name: Install dependencies
        run: npm ci
      - name: Unit tests
        run: npm test
      - name: Typecheck (all workspaces)
        run: npm --workspaces run typecheck --if-present
      - name: Docs snippets typecheck
        run: npm run docs:snippets
      - name: Lint
        run: npm run lint
      - name: Prettier check
        run: npm run format:check
      - name: Build components lib
        run: npm run build --workspace=@enterprise-ui/components
      - name: Build showcase
        run: npm run build --workspace=@enterprise-ui/showcase
      - name: Build docs site
        run: npm run build --workspace=@enterprise-ui/docs
      - name: Publish
        uses: changesets/action@6a0a831ff30acef54f2c6aa1cbbc1096b066edaf # v1.7.0
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
          publish: npm run release
          version: npm run version:packages
          commit: 'chore: version packages'
          title: 'chore: version packages'
```

- [ ] **Step 2: Validate the YAML and the OIDC bits**
