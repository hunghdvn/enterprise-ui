# DataGrid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mở rộng `Table` thành grid ERP duy nhất: multi-sort, pin trái/phải, virtual 10k, filter header, group + summary, master-detail, card mobile, phân trang, export CSV.

**Architecture:** Giữ `Table/` tại chỗ, không thêm component grid thứ hai. Logic lọc/sort/group/export là hàm pure trong `src/internal/` có unit test riêng; `Table.tsx` chỉ render theo props (presentational-only). `Pagination` có sẵn được nhúng qua prop.

**Tech Stack:** React 18.3+, TypeScript 5 strict, CSS Modules + `var(--...)`, Vitest + Testing Library + jsdom, Vite 5 lib build.

**Spec:** `docs/superpowers/specs/2026-10-12-datagrid-design.md`

## Global Constraints

- Zero runtime deps ngoài react/react-dom — cấm tailwind, antd, mui, headless libs.
- TypeScript strict, cấm `any` — dùng `unknown` + narrow khi cần.
- Styling duy nhất `*.module.css` + `var(--...)` — cấm hex cứng trong components, cấm import CSS chéo giữa components.
- Primary `#1E47C4`, hover `#1E40AF`, pale `#EFF6FF`; accent `#F97316` ~10%; light bg `#F8FAFC` surface `#FFFFFF` border `#E2E8F0` text `#0F172A` muted `#64748B`; dark bg `#0F172A` surface `#1E293B` border `#334155` text `#F8FAFC` muted `#94A3B8`.
- Default theme=light density=compact; row compact 32px / comfortable 44px.
- Presentational-only: data qua props, event qua `onSort`/`onColumnFilter`/`onToggleGroup`/`onToggleExpand`/`onPage`, không fetch.
- Contrast ≥4.5:1 light+dark; keyboard + focus-ring xanh; grid `role=grid`, `aria-sort` trên columnheader.
- Folder layout `X.tsx + X.module.css + types.ts + index.ts + X.test.tsx`, re-export từ `src/index.ts`.
- Vitest globals on (`test`/`expect`/`vi` không cần import).
