# Combobox Implementation Plan

> **Sub-skill:** executing-plans (TDD, task-by-task).

**Goal:** Combobox searchable + multi-select chips (controlled value/onChange).
**Architecture:** custom input + popover list; internal filter text; click-away/scroll close; position via `getBoundingClientRect` + flip.
**Tech:** React 18 TS strict · CSS Modules · inline SVG icons · vitest/jsdom (behavioral).
**Spec:** docs/superpowers/specs/2026-10-18-combobox-design.md

## Global Constraints

TS strict, zero runtime deps, CSS Modules + `var(--…)` tokens (no hex), presentational-only (props in / events out), inline SVG icons, vitest globals on.

## Review Focus

1. Controlled `value` sync (prop change → chips update).
2. `string` (single) vs `string[]` (multiple) type + onChange payload.
3. Filter text internal (no callback) — not leaked as controlled.
4. Positioning near viewport edge / scroll closes popover.
5. a11y: combobox/listbox/option roles, `aria-expanded`/`aria-selected`, keyboard.
