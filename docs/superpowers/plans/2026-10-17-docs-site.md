# Docs Site + Missing Components Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete 4 missing P1 components (Tabs, Tooltip, Empty, Spin), add showcase pages, and build a docs site using the library itself.

**Architecture:** Monorepo with 3 workspaces. New components follow existing folder layout. Docs site is a new Vite app (`apps/docs`) that consumes the built library. Docs content is colocated React components (no MDX). State-based routing (no react-router).

**Tech Stack:** React 18, TypeScript strict, CSS Modules, Vite, Vitest + Testing Library

**Spec:** `docs/superpowers/specs/2026-10-17-docs-site-design.md`

## Global Constraints

- Components: zero runtime deps (react only), CSS Modules only, `var(--…)` tokens, no hardcoded hex
- Folder layout: `X.tsx + X.module.css + types.ts + index.ts + X.test.tsx`
- TypeScript strict, no `any`
- Vitest globals on (`test`/`expect`/`vi` need no imports)
- Docs site consumes `@enterprise-ui/components` from `dist/` (must build first)
- Docs site imports `@enterprise-ui/components/style.css`
- All UI text in Vietnamese (matching existing codebase convention)

## Review Focus

- Keyboard navigation for Tabs (ArrowLeft/Right, Enter/Space)
- Tooltip positioning near viewport edges
- Empty state inside Table (integration)
- Spin fullscreen overlay z-index and scroll lock
- Docs site responsive breakpoint (sidebar → drawer)
- CodeBlock copy button clipboard API
- Search filtering with no results
